=============
ebdai package
=============

The :mod:`ebdai` package (version 1.0.1) holds BDI expansions. It is
versioned independently of :mod:`ex_fuzzy`. Import classifiers from
``ex_fuzzy``; import bias helpers and workshop datasets from ``ebdai``.

User guide: :doc:`../user-guide/ebdai`.
